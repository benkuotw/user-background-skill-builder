# User Background Skill Builder

This is an Antigravity agent skill designed to help users generate a specific skill based on their background. When the generated skill is invoked, the conversation will be more precise and tailored to you.

## Installation

1. Navigate to your project's `.agents/skills` directory:
   ```bash
   cd .agents/skills
   ```
2. Clone this repository into a directory named `user-background-skill-builder`:
   ```bash
   git clone https://github.com/benkuotw/user-background-skill-builder.git
   ```
   
## Usage

Once installed, simply ask your agent to build a skill based on your background:

> **/user-background-skill-builder** Build a skill based on my background and name it `my-name`
